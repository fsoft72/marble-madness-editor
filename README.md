# Marble Madness Editor

An editor for Marble Madness style games.

## About

- The whole project was written through "vibe coding", to test the capabilities of Google Gemini Argon.
- All the code was produced entirely by AI.

## Status

This is currently a **heavy work in progress**. More levels and game modes will be added in the future.
